# HY2 SOCKS Implementation Plan

**Goal:** 完成本次已确认的独立 HY2 SOCKS 管理范围，仅本地修改。

**Architecture:** 内核只读规范化 YAML；助手用 jq 创建节点独立 JSON；复用并扩展事务支持主配置更新和新增文件恢复。

**Tech Stack:** Bash、jq、Go、现有 yaml.v3、Python unittest 开发测试。

- [x] 为 YAML 读取添加拒绝重复键、多文档、非对象及超大输入的 Go 测试，随后实现只读命令。
- [x] 为两节点共享源文件添加助手隔离、替换/删除、UDP 与只读密码隐藏测试，先确认当前版本失败。
- [x] 在 src/helper.sh 增加 HY2 适配函数；仅改变所选节点路径；用私有元数据验证未被人工修改。
- [x] 扩展事务备份/漂移/恢复，记录主配置应用后摘要及新增文件的原始缺失状态；测试部分写入与启动失败。
- [x] 更新菜单能力判断、文档和版本，重新生成发布脚本与 SHA256SUMS。
- [x] 运行 Go 测试、助手与管理测试、完整 Python 测试、脚本语法和摘要校验；检查最终 diff，不推送或部署。
