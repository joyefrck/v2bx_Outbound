# 菜单内更新助手

**Goal:** 用户从主菜单 `6. 检查 / 更新助手` 更新当前服务器上的助手，无需重复查找下载命令。

**Architecture:** 通过 GitHub API 读取 main 的提交 SHA，按该不可变提交下载助手和 SHA256SUMS。验证校验值与语法后静态读取版本，显示差异并确认。备份正在运行的助手文件，检查并发修改后原子替换。退出旧菜单时清理临时文件并释放锁，再启动新版菜单。整个流程不修改节点配置、不重启 V2bX。

**Tech Stack:** 保持 Bash + jq + curl，版本 2.2.0；无定时任务或新后台服务。

- [x] 实现提交 SHA 解析、不可变下载、版本比较、备份与原子替换。
- [ ] 验证更新后的菜单重启释放旧锁，保留原有事务清理行为。
- [ ] 接入菜单 6，更新文档、独立脚本和校验文件；完成测试后发布。
