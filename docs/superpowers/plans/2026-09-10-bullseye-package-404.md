# Debian 11 AMD64 软件包 404 修复

用户截图显示 libjq1 的 AMD64 包下载失败。实测 live security 源的 `libjq1_1.6-2.1%2bdeb11u3_amd64.deb` 返回 404，而原始加号地址返回 200；官方 20260831T235959Z 快照的两种地址均返回 200，SHA256 与 Packages 索引一致。

只把临时安全源换成固定官方快照，继续保留签名和包哈希校验；普通源更新成功但安装失败时也允许 Debian 11 进入恢复流程。

补充模拟安装阶段 404 测试。新增 CI 的原生 AMD64 Debian 11 实际安装任务，安装所有依赖、运行 jq、检查 dpkg 状态并确认原有源文件保持不变。此前 ARM64 验证不作为 AMD64 安装成功的依据。
