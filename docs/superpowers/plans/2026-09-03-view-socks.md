# SOCKS 配置查看菜单

**Goal:** 在主菜单增加 `5. 查看 SOCKS 出口配置`，让用户能够核对每个节点已经保存的接入信息。

**Architecture:** 直接读取当前主配置及关联出站/路由文件，按本助手的节点专用出站标识显示地址、端口、用户名、隐藏后的密码和 UDP 设置。没有记录、路由缺失、配置无效及不支持的内核分别提示。额外提供只读 `--show-socks` 命令供终端查询。查看不探测网络，不修改配置，不启动或停止服务。

**Tech Stack:** 保持 Bash + jq + curl；版本更新为 2.1.0。
