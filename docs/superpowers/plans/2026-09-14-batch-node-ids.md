# 批量节点 ID 实现计划

**目标：** 在生成配置和增量新增节点的共用向导中，一次填写多个 ID，复用同一组面板、内核、协议及证书配置；保留逐个填写。

**设计：** 扩展已有 Node ID 输入，不额外插入模式选择菜单。单个 ID 仍执行原流程；多个 ID 使用英文逗号、中文逗号或空格分隔。每项沿用原有 1 至 10 位正整数限制，拒绝重复 ID、空项、范围和非数字输入。每组生成独立的节点对象，除 NodeID 外字段完全一致。

**范围：** 沿用当前 main 分支。增量新增仍由现有事务校验、备份及保存，失败不保存半批节点。继续添加可以填写另一组配置。生成配置时也拒绝跨组重复的面板、协议和 ID 组合。

**技术：** Bash、jq、Python unittest。
