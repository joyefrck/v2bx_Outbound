# SSH 断开后继续应用配置

目标：用户已要求修复确认保存导致断连回滚的问题。采用上一轮实际验证成功的一次性 systemd 任务，不增加运行依赖；保持当前分支。

设计：确认后复制候选配置和助手到 root 私有任务目录，记录任务动作与原始摘要，通过 systemd-run 启动独立进程。原菜单释放配置锁并等待结果；SSH 挂断只结束菜单。工作进程获取同一锁，复核原配置、执行现有事务和服务检查，失败回滚。恢复备份复用同样路径。任务结果在再次打开菜单和 --last-job 中显示。任务完成清理含认证信息的工作副本，保留日志、结果及正常配置备份。

安全边界：不自动降级为前台操作；启动失败不改配置；未知运行状态不报告成功；完整保留备份和漂移检查；结果与日志不打印密码；不改变系统网络、SSH、节点认证或 UDP 选择。

- [x] 实现队列、工作进程、锁交接和结果显示，保存/恢复入口改走后台。
- [x] 更新版本、文档和构建产物，执行全部测试及 Bash 语法/摘要校验。
