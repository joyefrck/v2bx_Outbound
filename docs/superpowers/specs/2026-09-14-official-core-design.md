# 官方内核构建与更新设计

用户已批准推荐方案并要求实施。保留当前分支，源码整合到本仓库。

V2bX 内嵌 Xray、sing-box、Hysteria 2。维护 runtime/ 下的 V2bX 源码及来源许可证，锁定官方标签、提交、工具链和必要适配。发布独立 core-* 构建，菜单 13 从本仓库经过验证的发布读取清单和包；不回退到旧 V2bX 发布源。

区分实际安装、官方最新、已适配可安装三种版本。构建清单记录真实依赖而非仅显示声明版本。官方新版发现只能生成候选，不能自动绕过测试进入稳定通道。初次安装与更新共用受验证发布通道。Geo 数据独立记录，现有安装更新时保留现用文件。

下载并验证来源、摘要、解压路径、架构和配置后才可替换。后台任务持有共享锁，记录结果；更新与手动回滚保留配置、服务状态。服务失败恢复原文件，检查稳定 PID、重启计数和监听端口。实际协议连接、用户变更、流量统计和 SOCKS 出口通过后才允许发布。

## 验收
- 官方源码依赖可构建，不以旧修改版冒充官方最新版。
- 没有兼容发布时明确说明，不安装未经验证候选。
- SHA/架构/配置检查失败不停止服务；同内容更新不重启。
- SSH 断线不终止应用任务；失败恢复及手动回滚均可验证。
- 测试、构建、发布、服务器上线分别报告证据。
