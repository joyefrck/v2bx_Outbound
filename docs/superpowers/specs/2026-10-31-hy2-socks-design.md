# 独立 Hysteria2 SOCKS 出口

沿用本次对话已确认的范围：菜单 3 支持独立 HY2 的配置、更换、查看、删除和回滚；本次只改代码，不发布。

## 方案

复用内核已有 YAML 库提供只读 `hy2-config-json` 命令，助手仍只依赖 Bash/jq/curl 和已安装内核。比自行实现 YAML 子集更可靠，也不需要额外安装 yq/Python。旧内核缺少命令时明确提示需要配套更新，不尝试修改文件。

首次配置为所选节点创建私有 JSON 文件（HY2 的 Viper 原生支持 JSON），只更新该节点的 Hysteria2ConfigPath。共享原文件和其他节点保持不变。私有文件保存原配置及助手标记，以支持更换和精确恢复；删除出口后保留该节点独立文件，内容恢复为原配置。

SOCKS 作为所有允许流量的出口，保留 reject 规则，将原有 direct 规则指向 SOCKS，追加全匹配兜底。UDP 不受支持时设置 disableUDP。外部 ACL、自定义非 direct 出站或助手配置被人工改动时拒绝自动覆盖。

扩展现有事务以备份主配置及原本不存在的文件，支持失败回滚、手动恢复、后台任务及并发漂移检查。兼容原有 schema 1/2 备份。查看只读且隐藏密码。

## 验收

覆盖 YAML 规范化、重复键/多文档拒绝、两节点共享配置隔离、替换与删除恢复、TCP/UDP、密码转义与隐藏、旧内核、复杂路由拒绝、写入/启动失败及手动回滚、后台应用。原有 Xray/sing-box 测试继续通过。
