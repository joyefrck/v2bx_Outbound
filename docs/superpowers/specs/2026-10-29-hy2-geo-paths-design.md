# HY2 规则库路径统一

## 范围

沿用已确认的服务端修复：独立 Hysteria2 生成配置明确引用管理工具正式配置目录中的 `geoip.dat` 和 `geosite.dat`，避免服务工作目录中自动下载的另一套数据库改变通用 ACL 判断。不添加任何业务域名或 IP 白名单，不修改客户端或面板订阅。

## 设计

在 `src/manager/templates.sh` 的公共模板中写入 `acl.geoip` 和 `acl.geosite`。管理工具生成候选文件时，路径取最终的 `M_CONFIG`，不能引用后续会删除的候选目录；单独调用模板函数时以调用方提供的目标目录为准。路径使用兼容 YAML 的 JSON 字符串转义。原有 DNS、ACL 顺序和出站行为保持不变。

新装、重新生成整套配置和新增 HY2 节点共用此模板。已有节点 YAML 和显式自定义路径不自动迁移；只更新管理工具不会修复已有配置。已有 HY2 节点可显式补上两个路径后检查、重启。此次只上传 GitHub，不发布新内核或修改其他服务器。

## 验收

回归覆盖候选目录与最终目录分离、候选目录删除后引用仍有效、独立模板调用、路径转义及新增节点保留旧 YAML。实际 HY2 运行测试使用本地面板和临时证书，删除候选目录、在另一个工作目录放置无效数据库，并禁止外部下载；要求进程成功拉取用户并监听 UDP，正式数据库和原配置保持不变。此测试加入双架构内核 CI。运行本地全套脚本测试、实际内核配置预检查、脚本生成一致性与 SHA256 校验。管理工具版本更新为 3.7.2。
